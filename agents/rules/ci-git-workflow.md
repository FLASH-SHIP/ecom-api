## Git Workflow

- Branch naming: `feat/blog-categories`, `fix/auth-refresh-token`, `refactor/user-service`
- Commit messages follow conventional commits: `feat(blog): add category tree`
- Create PRs as draft by default
- Never force push or rebase shared branches
- Squash merge to main

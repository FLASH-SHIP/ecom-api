# Technical Reference: System NPM Scripts & Monorepo Workflows

This document provides a comprehensive technical guide for all executable scripts configured across the Ecom Monorepo system (`package.json` root and workspace packages).

---

## 1. Monorepo Architecture Overview

The system uses **Yarn v4 Workspaces** combined with **Turborepo v2** for task execution, caching, and dependency graph management.

### Workspace Packages Summary
- `apps/web`: Next.js 16 Admin CMS (App Router) — `@ecom/web`
- `apps/admin`: Additional Admin UI modules — `@ecom/admin`
- `apps/customer`: Next.js Customer Portal — `@ecom/customer`
- `apps/api`: NestJS REST API v2 — `@ecom/api`
- `packages/prisma`: PostgreSQL Prisma ORM schema & migrations — `@ecom/prisma`
- `packages/features`: Vertical slice domain logic — `@ecom/features`
- `packages/trpc`: Internal tRPC API layer — `@ecom/trpc`
- `packages/ui`: Shared Radix & Tailwind UI components — `@ecom/ui`
- `packages/lib`: Shared utilities, errors, and auth helpers — `@ecom/lib`

## 2. Development Scripts (`yarn dev*`)

Commands for starting local hot-reloading development servers.

| Script Command | Target / Executed Command | Description |
| :--- | :--- | :--- |
| `yarn dev` | `turbo run dev` | Starts development servers for **all applications** (`apps/*`) simultaneously in parallel. |
| `yarn dev:admin` | `turbo run dev --filter=@ecom/admin` | Starts the Admin Web application development server only (`http://localhost:3000`). |
| `yarn dev:customer` | `turbo run dev --filter=@ecom/customer` | Starts the Customer Portal application development server only (`http://localhost:3001`). |
| `yarn dev:api` | `turbo run dev --filter=@ecom/api` | Starts the NestJS REST API development server only with `tsx watch` hot-reload (`http://localhost:4000/api/v1`). |

## 3. Build & Type Safety Scripts (`yarn build`, `yarn type-check*`)

Commands for compilation, bundling, and TypeScript type checking.

| Script Command | Target / Executed Command | Description |
| :--- | :--- | :--- |
| `yarn build` | `turbo run build` | Builds production bundles for all applications and workspace packages according to Turborepo dependency order. |
| `yarn type-check` | `turbo run type-check` | Runs `tsc --noEmit` across all 15 monorepo packages to verify type correctness without outputting JS files. |
| `yarn type-check:ci` | `yarn db:check-drift && turbo run type-check --force` | **Mandatory CI Pipeline Gate.** Executes `db:check-drift` first to verify database schema synchronization, then forces a clean type-check across all packages bypassing Turborepo cache. |

## 4. Code Quality, Formatting & Testing Scripts

Commands for code linting, automated formatting, unit tests, and Playwright E2E suites.

| Script Command | Target / Executed Command | Description |
| :--- | :--- | :--- |
| `yarn lint` | `biome check .` | Checks code formatting, linting rules, and imports across the monorepo using Biome v2. |
| `yarn lint:fix` | `biome check --write .` | Automatically fixes all auto-fixable linting and formatting issues across the repository. |
| `yarn format` | `biome format --write .` | Formats all source code files according to Biome formatting rules. |
| `yarn test` | `turbo run test` | Executes unit tests using Vitest across all workspace packages. |
| `yarn test:ci` | `turbo run test -- --reporter=junit --outputFile=test-results.xml` | Runs unit tests in CI mode generating JUnit XML output reports for pipeline analytics. |
| `yarn e2e` | `playwright test` | Runs headlessly all Playwright End-to-End browser integration tests. |
| `yarn e2e:ui` | `playwright test --ui` | Launches interactive Playwright UI mode for visual debugging and time-travel inspection. |
| `yarn e2e:report` | `playwright show-report` | Opens the HTML test report generated by the last Playwright test run. |

## 5. Database & Prisma Lifecycle Scripts (`yarn db:*`, `yarn prisma:*`)

Commands for managing database schema migrations, schema drift detection, seeding, and database studio inspection.

| Script Command | Target / Executed Command | Description |
| :--- | :--- | :--- |
| `yarn db:check-drift` | `yarn workspace @ecom/prisma db:check-drift` | Verifies that PostgreSQL database schema and `packages/prisma/schema/*.prisma` models are 100% synchronized with `migrations/` SQL files using `prisma migrate status`. Exit code `0` indicates full sync; non-zero indicates drift. |
| `yarn db:reset` | `yarn workspace @ecom/prisma db:reset` | **Developer Workspace Reset.** Drops all local database tables, applies all migration SQL files from scratch, and seeds core reference and business data. |
| `yarn prisma:generate` | `yarn workspace @ecom/prisma prisma generate` | Regenerates the Prisma Client TypeScript types in `packages/prisma/src/generated/prisma/client`. |
| `yarn prisma:migrate` | `yarn workspace @ecom/prisma prisma migrate dev` | **Development Migration Creator.** Compares `.prisma` changes with local PostgreSQL, prompts for a migration name, creates a new `migration.sql` file, applies it, and updates Prisma Client types. |
| `yarn prisma:seed` | `yarn workspace @ecom/prisma db:seed` | Executes the complete database seeder orchestrator (`seed.ts`), running all registered seeders. |
| `yarn prisma:seed:core` | `yarn workspace @ecom/prisma prisma:seed:core` | Executes **System Core Reference Seeders** only (Roles, Permissions, Languages, Settings, Divisions, Countries). |
| `yarn prisma:seed:business` | `yarn workspace @ecom/prisma prisma:seed:business` | Executes **Business Data Seeders** only (Rate Cards, Customer Groups, Sample Customers). |
| `yarn prisma:seed:nestjs` | `yarn workspace @ecom/api db:seed` | Runs API-specific seed bootstrapping script (`apps/api/src/seed.ts`). |
| `yarn prisma:studio` | `yarn workspace @ecom/prisma prisma studio` | Opens Prisma Studio visual database GUI in browser at `http://localhost:5555`. |

## 7. Infrastructure & Environment Management Scripts

Commands for Docker container management, environment setup, and cleaning build artifacts.

| Script Command | Target / Executed Command | Description |
| :--- | :--- | :--- |
| `yarn docker:up` | `docker compose up -d` | Boots local PostgreSQL 18 and Redis services in background Docker containers. |
| `yarn docker:down` | `docker compose down` | Stops and removes local PostgreSQL and Redis Docker containers. |
| `yarn clean` | `turbo run clean && rm -rf node_modules` | Cleans all `.turbo`, `dist`, `.next` build caches and deletes root `node_modules`. |
| `yarn prepare` | `husky` | Initializes Husky Git hooks for local pre-commit checks. |

## 8. Best Practices Checklist for Developers & AI Agents

1. **Before pushing any PR:**
   ```bash
   yarn type-check:ci
   yarn lint
   ```
2. **When modifying Prisma schema:**
   ```bash
   yarn prisma:migrate --name <descriptive_name>
   yarn db:check-drift
   ```
3. **When resetting local dev environment:**
   ```bash
   yarn db:reset
   ```
